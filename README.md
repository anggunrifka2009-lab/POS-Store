## 📖 Deskripsi

Aplikasi POS (Point of Sale) adalah aplikasi kasir berbasis Android yang digunakan untuk mengelola transaksi penjualan, produk, kategori, pegawai, dan cabang. Aplikasi juga dilengkapi fitur autentikasi pengguna dan pencetakan struk transaksi.
